第四步 dì sì bù · Bước bốn

Collect two free keys

10 minutes · needs: a Google account
›

The daily robot needs two library cards: one to search YouTube, one to ask an AI teacher for phrases. Both are free and both come from Google. A key is a long password made of letters and numbers: treat it like one.

Key 1: Gemini (the AI teacher)

  1. Open aistudio.google.com/apikey and sign in.
  2. Press Create API key, then copy it.

Key 2: YouTube Data API (the video finder)

  1. Open the YouTube Data API v3 page in Google Cloud. Create a project if it asks (any name), then press Enable.
  2. Go to Credentials.
+ Create credentials›API key›Copy

Put the keys where the robot looks

On your computer the keys live in a small file called .env.local inside the project folder. That file is on the kit's "never upload" list, so it stays on your computer.

Say this to your AI helper 
Create the file .env.local in this project with two lines, GEMINI_API_KEY= and YOUTUBE_API_KEY=, then open it so I can paste my two keys in myself. Don't print the keys back to me and never commit this file.

Then give the same two keys to GitHub, so its own small daily job can run too: open your copy's secrets page and add them one at a time.

⚙ Settings›Secrets and variables›Actions›New repository secret
Name (exactly)Secret
GEMINI_API_KEYyour Gemini key
YOUTUBE_API_KEYyour YouTube key

Free means small. Gemini's free plan allows about 20 requests a day per model. The kit is tuned for that (6 new videos per language a day) and quietly switches to another Gemini model when one runs out. Prefer Claude as the teacher? Add ANTHROPIC_API_KEY and a repository variable AI_PROVIDER = claude.

Make the devices share one word list

8 minutes · optional, but it's the magic part
›

Firebase is a free Google notebook in the cloud. The TV, iPad and phones all write their ★ saved words and ✓ watched videos into it, so they stay in step. Right now your copy still points at the demo's notebook. Give your family its own:

  1. Open console.firebase.google.com › Create a project (any name; Analytics is not needed).
  2. In the left menu: Build › Realtime Database › Create Database. Pick the location nearest you and Start in locked mode.
  3. Open the Rules tab, replace everything with the rules below, and press Publish.
{
  "rules": {
    ".read": false,
    ".write": false,
    "sync": {
      "$id": {
        ".read": "$id.length >= 23",
        ".write": "$id.length >= 23",
        "flags": {
          "$video": {
            ".validate": "newData.hasChildren(['t']) && newData.child('t').isNumber()"
          }
        }
      }
    }
  }
}
  1. Go back to the Data tab and copy the address at the top. It looks like https://your-project-default-rtdb.firebaseio.com.

Wake up the daily robot

5 minutes · then it runs by itself
›

Every day the robot looks for new videos with real Chinese and Vietnamese subtitles, asks the AI teacher for 8 to 12 useful phrases in each, adds five new words per language, and publishes everything to your site.

Say this to your AI helper 
Run the daily update once now (scripts/run_local.sh on a Mac, scripts\run_local.bat on Windows) and show me what it added. Then schedule it to run every morning at 6:30 on this computer: use scripts/install_daily_mac.sh on a Mac, or Windows Task Scheduler on Windows.

Prefer doing it by hand?

Run onceEvery morning
Mac./scripts/run_local.sh./scripts/install_daily_mac.sh
Windowsdouble-click scripts\run_local.batTask Scheduler › Create Basic Task › Daily › start run_local.bat

Why your own computer? YouTube happily hands subtitles to a home internet connection but usually refuses GitHub's servers. So GitHub's daily job adds the new words, and your computer adds the new videos. If the computer is asleep at 6:30, it catches up when it wakes.

Check GitHub's side once: open the Actions tab. If it asks, press I understand my workflows, go ahead and enable them.

When something sulks

  
My site shows a "404" page
Step 2 needs a minute or two the first time. Check that the folder is /docs (not / (root)) and that the project is Public. Still nothing after ten minutes? Ask your helper: "check why GitHub Pages is not publishing".

  
No new videos arrived today
  • The computer was off all day: the robot runs when it wakes up.
  • The AI teacher's free allowance was used up: it continues tomorrow by itself.
  • Look at the log: on a Mac ~/Library/Logs/family-language-kit.log. Or say to your helper: "run the daily update now and explain what happened".

  
A video says it cannot be played
Some channels forbid playing their videos outside youtube.com, and videos get deleted. The TV skips to the next one by itself. On the phone, the YT↗ button opens it in the YouTube app.

  
The subtitles or pinyin look a bit off
Many videos only have automatic subtitles, and the AI teacher is good but not perfect. Videos with subtitles made by the channel itself are preferred. If a video is poor, archive it (🗂) and it leaves the rows on every device.

  
The TV does not read words aloud
Most TVs have no voice for Chinese or Vietnamese built in. Phones, iPads and computers do: the 🔊 buttons and the games speak there.

  
Does this cost anything, ever?
Not at these sizes. GitHub (site and daily job), Gemini's free plan, YouTube's free search allowance (10,000 units a day; the kit uses about 1,300) and Firebase's free plan are all far bigger than one family needs. No credit card is required for any of them.

  
What do the kids see? Is it safe?
Video search runs with YouTube's strict SafeSearch, only from the topics and channels in sources.json, and you can remove any video with 🗂. It is still YouTube, so the first few times, watch together. 一起看 yìqǐ kàn · cùng xem.
